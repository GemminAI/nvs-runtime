## Scope

Maintainers support:

- The stable Runtime API
- Built-in provider contracts and offline behavior
- Documentation accuracy

Upstream SDK or daemon bugs (MCP, Kernel, external HEKB services) should be reported to those projects when the defect is outside this repository’s adapter boundary.
